# Mockups

Static HTML, one file per screen, all styled by `glass.css` (the source for the app's CSS). Open them in a browser at 1920 by 1080; `phone.html` at 390 wide.

| File | Screen |
| --- | --- |
| glass.css | Tokens and components. Copy to apps/web/src/styles/glass.css unchanged |
| shelf.html | Shelf, on the TV |
| shop.html | Shop: the live browser panes |
| order.html | Order: waiting for a yes. Other states are described at the bottom of the file |
| phone.html | Phone: approve, name a new part, counts |

Why, Teach and Ops are described in docs/UI.md and built from the same components.

The dark board in shelf.html is a drawing that stands in for the camera feed. The grey bars in shop.html stand in for the live browser.
